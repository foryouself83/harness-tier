# E2E CI 안전망 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** harness-tier가 소비자 저장소에 E2E CI 워크플로를 배달하고, host config의 불리언
하나로 켜지게 한다. 차단하지 않는 다섯 번째 CI 안전망.

**Architecture:** 토큰 없는 복사(`_render_one(src, dest, {}, label)`) + `flow-config.e2e.enable`
불리언 게이트. 템플릿은 Playwright를 리터럴로 부르고, 첫 스텝이 저장소에서 `playwright.config.*`를
찾아 없으면 나머지 스텝을 전부 건너뛴다(`wiki-verify`의 스텝 가드와 같은 모양). 다중 앱 팬아웃은
Playwright `projects[]`에 위임하고 그 설정은 `skills/playwright-scaffold/`가 소유한다.

**Tech Stack:** Python 3.8+ · PyYAML · pytest · GitHub Actions · Playwright

**Spec:** [E2E CI 안전망 — 설계](../specs/2026-09-08-e2e-ci-design.md)
(`docs/superpowers/specs/2026-09-08-e2e-ci-design.md`) — 결정 14개 전부 확정. 이 계획은 그 문서에서만 논증을 가져온다.

## Global Constraints

- **저장소는 영어** — 문서 · 커밋 메시지 · 주석/독스트링 · 테스트 assertion 메시지. 게이트/CLI
  출력 문자열은 한국어가 유지 대상이다(`_render_one`의 반환 줄이 그렇다). 이 계획서와 스펙만
  한국어 예외(`CLAUDE.md` Conventions).
- **프로즈 100자** — `scripts/doc_style_check.py:52` `MAX_LINE = 100`. `|`가 있는 줄은 면제.
- **모든 렌더 경로는 비파괴** — dest가 있으면 보고만 하고 덮지 않는다. `_render_one:918-919`.
- **템플릿에 `__HARNESS_*__` 토큰 0개** — D6. 치환맵은 `{}`.
- **`run:` 블록에 `${{ }}` 금지** — `tests/flow_init/test_workflow_contexts.py`의 allow-list는
  `matrix` · `steps`뿐이고 E2E는 둘 다 쓰지 않는다. `if:` · `concurrency:`에서는 허용된다.
- **모든 job에 `timeout-minutes`** — `test_all_github_workflow_templates_have_timeout`이 글롭으로
  쓸어 담으므로 새 템플릿도 자동 대상이다.
- **`.github/workflows/`는 `HARNESS_DIR` 예외** — GitHub이 위치를 강제한다(`CLAUDE.md:113-114`).
- **FAIL-OPEN** — 렌더 실패는 보고이지 예외가 아니다. 게이트를 막지 않는다.
- **커밋 타입** — `github/` · `flow-config.example.yaml` · `skills/` · `rules/` · `USAGE*.md`는
  전부 소비자 대면이므로 `feat`. `tests/` · `evals/`는 `test:`, `CLAUDE.md`는 `docs:`.
- **`skills/flow-init/SKILL.md`는 500줄 cap** — 현재 486줄(`tests/skills/test_frontmatter.py:65`).
  Task 5의 추가는 6줄 이내.

# harness-tier E2E CI - rendered as-is by /flow-init when flow-config.e2e.enable is true
# (no config tokens). Layer-3 safety net: the layer-2 gates see only Claude-session commits,
# so an integration regression arriving via a terminal/direct/CI commit surfaces here.
#
# This workflow BLOCKS NOTHING. It is the fifth net beside unit-test.yml, api-contract.yml,
# wiki-verify.yml and doc-style.yml. Making it a required status check is a separate decision
# with preconditions - read the checklist at the bottom before touching a branch ruleset.
#
# SCOPE: a Playwright suite on a Linux runner. A non-web project (Windows desktop UI, a CLI,
# a REST-only backend) gets nothing from this file - leave flow-config.e2e.enable at false and
# see api-contract.yml / unit-test.yml instead.
#
# This is a STARTING POINT YOU OWN. /flow-init never overwrites it, so a later fix to the
# plugin's template does not reach this file. Edit the four EDIT markers below.
#
# Cost: one run is roughly (deps + browsers) + (stack up) + (suite) + teardown. For a
# three-app monorepo expect 35-50 minutes. Private-repo minutes are shared across every
# workflow in the account; public repositories run standard runners free.
name: e2e

on:
  push:
    branches: [stage, main]     # EDIT 1 - promotion branches. Adding your integration branch
                                # roughly doubles the monthly minutes.
  workflow_dispatch:            # produces a missing check without an empty commit

permissions:
  contents: read

concurrency:
  group: e2e-${{ github.ref }}
  cancel-in-progress: false     # a cancelled run reports `cancelled`, which is not a success
                                # and is never re-run automatically. GitHub still cancels a
                                # PENDING run when a newer one queues; that is not configurable.

jobs:
  e2e:
    runs-on: ubuntu-latest
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v7
        with:
          persist-credentials: false   # otherwise GITHUB_TOKEN sits in .git/config for every
                                       # later step, including dependency postinstall scripts

      # The other half of the enable boolean: that boolean is a RENDER switch, so a repo that
      # turned it on before writing a suite would go permanently red without this. Searching
      # below the root on purpose - a monorepo keeps its config in the app directory, and a
      # root-only check would report "nothing to run" while a suite sat one level down.
      - name: Detect a Playwright suite
        id: detect
        run: |
          if find . -maxdepth 3 -name 'playwright.config.*' -not -path './node_modules/*' \
               | grep -q .; then
            echo "found=true" >> "$GITHUB_OUTPUT"
          else
            echo "found=false" >> "$GITHUB_OUTPUT"
            echo "no playwright.config.* in this checkout - nothing to run"
          fi

      - uses: actions/setup-node@v6    # EDIT 2 - your runtime(s)
        if: steps.detect.outputs.found == 'true'
        with:
          node-version: "20"
          cache: npm

      - name: Start the stack          # EDIT 3 - delete this step and Teardown if your
        if: steps.detect.outputs.found == 'true'   # Playwright config starts what it needs
        env:                                       # via `webServer`
          COMPOSE_FILE: docker-compose.yml
        run: docker compose -f "$COMPOSE_FILE" up -d

      - name: Wait for the API
        if: steps.detect.outputs.found == 'true'
        env:
          URL: http://localhost:8000/health
          TIMEOUT: "120"
        run: |
          case "$TIMEOUT" in ''|*[!0-9]*) echo "TIMEOUT must be digits" >&2; exit 1 ;; esac
          i=0
          until curl -sf -- "$URL" >/dev/null; do
            i=$((i+2))
            [ "$i" -lt "$TIMEOUT" ] || { echo "health timeout: $URL" >&2; exit 1; }
            sleep 2
          done
        # Do NOT wait here on a URL your Playwright `webServer` starts - it is not up yet.
        # Do NOT write this as `for u in <list>` or wrap it in `sh -c`: both re-parse the
        # value as shell. Keep every URL in `env:` and read it as "$URL".

      - name: Install dependencies and browsers
        if: steps.detect.outputs.found == 'true'
        working-directory: .           # EDIT 4 - your test package, e.g. e2e/ or apps/web/.
        run: npm ci && npx playwright install --with-deps chromium   # Keep it the SAME in the
                                                                     # E2E step below.

      - name: E2E
        if: steps.detect.outputs.found == 'true'
        env:
          BASE_URL: http://localhost:3000
        working-directory: .           # EDIT 4 (second half) - keep in step with the above.
        run: npx playwright test
        # One `projects[]` entry per app in playwright.config keeps every app in this one run:
        # they execute in parallel, every failure is collected, and one report covers them all.
        # A second suite step here would stop at the first failure and hide the rest.
        # `/playwright-scaffold` writes that config, including the trace policy the commented
        # upload step below depends on.

      # Reports embed request and response bodies, screenshots and session tokens. On a public
      # repository every artifact is world-readable for its retention period, with no token.
      # Uncomment only after confirming `trace`/`video` policy in playwright.config.
      # - name: Upload report
      #   if: always() && steps.detect.outputs.found == 'true'
      #   uses: actions/upload-artifact@v6
      #   with:
      #     name: e2e-report
      #     path: playwright-report
      #     retention-days: 1

      - name: Teardown
        if: always() && steps.detect.outputs.found == 'true'
        env:
          COMPOSE_FILE: docker-compose.yml
        run: docker compose -f "$COMPOSE_FILE" down
        # `down`, not `down -v`: on an ephemeral runner the flag buys nothing, and it destroys
        # named volumes the day someone moves this job to a machine of their own.

# Making this a required status check
# ----------------------------------
# Only with all four of these, or not at all:
#   1. add a `pull_request:` trigger - a check that never reports leaves a PR blocked on
#      "Waiting for status to be reported", and a check required on direct pushes deadlocks,
#      because the push that would produce it is the push being refused;
#   2. keep `workflow_dispatch:` - it is how you produce a missing check during an incident;
#   3. give the ruleset a bypass actor, or agree in writing who edits the ruleset when E2E
#      breaks for a reason unrelated to the change;
#   4. know that fork PRs get no secrets, so a credentialed suite red-lights every outside
#      contribution.
# The plugin does not set this up. It blocks nothing on its own.

```python
def render_e2e_workflow(host: Path, plugin: Path) -> list[str]:
    """Copy e2e.yml as-is — no tokens, gated by one boolean.

    Gated where wiki-verify and doc-style are not: those two no-op green because their own
    script exits 0 without its config, and a repo that never opted in pays nothing. E2E has
    no such script — its no-op is a step inside the template — so a consumer with no browser
    front end would still spend a runner on every push to a promotion branch.

    The boolean is a RENDER switch, not a run switch. Setting it back to false leaves an
    already-rendered file running; deleting .github/workflows/e2e.yml is what stops it. That
    asymmetry is why the report below names the scaffold rather than the flag.

    Idempotent·non-destructive (existing dest → report only), like every render here.
    """
    cfg = load_e2e_config(host)
    if cfg is None:
        return ["  [=] e2e 미설정 — 워크플로 skip"]
    if not cfg.get("enable"):
        return ["  [=] e2e.enable=false — 워크플로 미설치"]
    out = _render_one(plugin / E2E_TEMPLATE, host / E2E_DEST, {}, "e2e 렌더")
    # Delivery is a human trigger (D8 = the scaffold owns playwright.config.*), so the one
    # state the boolean cannot prevent is "workflow rendered, no suite anywhere". The
    # template's detect step keeps that green; this line is how it stops being permanent.
    if not any(host.glob("playwright.config.*")) and not any(host.glob("*/playwright.config.*")):
        out.append("  [i] playwright.config.* 없음 — /playwright-scaffold 로 먼저 만드세요.")
    return out
```
