# LLM Wiki Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** harness-tier 플러그인에 임베딩 없는 LLM Wiki를 추가한다 — YAML Front Matter에서
기계적으로 Knowledge Graph를 만들고, 검증을 flow gate에 물리고, `doc-sync`가 코드 stale을 해소한다.

**Architecture:** 신규 `scripts/wiki_graph.py` 하나가 build·verify·stale·neighbors를 전부
담당한다(PyYAML 외 의존 없음). 검증은 `flow-tiers.yaml`의 `wiki` runtime gate로 등록되어
기존 `--module-commands` → `precommit-runner.sh` 통로를 그대로 타므로 셸은 수정하지 않는다.
`/wiki-init`(신규 스킬)이 기존 문서를 대화형으로 이관하고, `doc-sync`에 Mode W가 붙는다.

**Tech Stack:** Python 3.8+ · PyYAML · pytest · Claude Code skill/plugin 규격

**Spec:** [2026-08-06-llm-wiki-design.md](../specs/2026-08-06-llm-wiki-design.md)

## Global Constraints

- **의존은 PyYAML만.** 토크나이저·네트워크·추가 패키지 금지. 예산 단위가 토큰이 아니라 줄인
  이유가 이것이다.
- **Invariant 1 (FAIL-OPEN)** — 내부 오류·설정 파손은 통과시킨다. `wiki_graph.py`가 블록하는
  것은 **정상 파싱된 wiki에서 발견된 규칙 위반**뿐이다.
- **Invariant 2 (Windows 인코딩)** — 모든 진입점에서 `force_utf8_io()` 호출, 모든 파일 I/O에
  `encoding="utf-8"` 명시. 누락하면 cp949에서 UnicodeEncodeError → FAIL-OPEN으로 게이트가 죽는다.
- **호스트 경로 절대 하드코딩 금지** — 읽기는 `${CLAUDE_PLUGIN_ROOT}`, 쓰기는
  `${CLAUDE_PROJECT_DIR}`. 스크립트 안에서는 `_harness_paths.host_root()`를 쓴다.
- **import 관용구** — 복사본/패키지 두 모드 모두에서 살아야 한다:
  ```python
  try:
      from _harness_paths import force_utf8_io, host_root
  except ImportError:
      from scripts._harness_paths import force_utf8_io, host_root
  ```
- **`id` 정규식**: `^[a-z0-9-]+(\.[a-z0-9-]+)*$`
- **defect 판별자**: `id`가 `defect.` 로 시작
- **block = exit 1** (`wiki_graph.py` 기준). PreToolUse의 exit 2는 `precommit-runner.sh`가
  변환한다 — 스크립트가 직접 2를 쓰지 않는다.
- **`--stale` · `--neighbors`는 항상 exit 0.** 조회가 커밋을 막지 않는다.
- **커밋 타입은 `feat(wiki):`** — consumer-facing `.md`가 바뀌므로 `docs`로 커밋하면 버전이
  오르지 않아 소비자에게 전파되지 않는다. 제목 50자 / 본문 72자 (gitlint).
- **lint**: `uv run ruff check && uv run ruff format --check` 통과 필수.

```python
# scripts/wiki_graph.py
"""LLM Wiki graph builder / verifier (harness-tier).

Front Matter 를 기계적으로 파싱해 Knowledge Graph 를 만들고 검증한다. 임베딩·LLM 을 쓰지
않으며 의존은 PyYAML 하나다. `--build` 는 doc-sync 가, `--verify` 는 flow gate 가 부른다.

wiki 미설치(설정 없음·enable:false·root 디렉터리 없음)면 모든 서브커맨드가 조용히 통과한다.
"""

from __future__ import annotations

from pathlib import Path

try:
    from _harness_paths import config_path, force_utf8_io, host_root
except ImportError:
    from scripts._harness_paths import config_path, force_utf8_io, host_root

# flow-config.wiki 의 기본값 SSOT. 호스트가 적지 않은 슬롯은 여기서 채운다.
_DEFAULTS = {"max_lines": 400, "context_lines": 2000, "defect_rule_threshold": 3}


def load_wiki_config(root: Path) -> dict | None:
    """flow-config.wiki 를 읽어 기본값을 채운 dict, wiki 가 없으면 None.

    None 은 "검사할 wiki 가 없다"는 뜻이며 호출자는 조용히 통과해야 한다. 설정 파손도
    None 이다 (Invariant #1 FAIL-OPEN — 깨진 설정으로 커밋을 막지 않는다).
    """
    cfg = config_path(root)
    if not cfg.is_file():
        return None
    try:
        import yaml

        data = yaml.safe_load(cfg.read_text(encoding="utf-8")) or {}
    except Exception:
        return None
    wiki = data.get("wiki")
    if not isinstance(wiki, dict) or not wiki.get("enable"):
        return None
    wiki_root = str(wiki.get("root") or "docs/")
    if not (root / wiki_root).is_dir():
        return None
    out = dict(_DEFAULTS)
    out.update({k: v for k, v in wiki.items() if v is not None})
    out["root"] = wiki_root
    if not out.get("index"):  # 미기재 또는 빈 값 → root 기준 기본 진입점
        out["index"] = f"{wiki_root.rstrip('/')}/index.md"
    return out
```

```python
_FM_DELIM = "---"


def parse_front_matter(text: str) -> dict | None:
    """선두 `---` 블록을 YAML 로 파싱한다. 없거나 깨졌으면 None.

    None 은 "wiki 노드가 아니다"와 "Front Matter 가 깨졌다"를 함께 뜻한다. 후자를 노드로
    실어 검증에 넘기면 파싱 실패가 block 이 되어 FAIL-OPEN 을 깬다 — 둘 다 무시가 맞다.
    """
    if not text.startswith(_FM_DELIM):
        return None
    end = text.find(f"\n{_FM_DELIM}", len(_FM_DELIM))
    if end < 0:
        return None
    try:
        import yaml

        front = yaml.safe_load(text[len(_FM_DELIM) : end + 1])
    except Exception:
        return None
    return front if isinstance(front, dict) else None


def collect_nodes(root: Path, wiki: dict) -> list[dict]:
    """wiki root 아래 Front Matter 를 가진 .md 를 경로 정렬 순으로 수집한다."""
    base = root / wiki["root"]
    nodes: list[dict] = []
    for path in sorted(base.rglob("*.md")):
        try:
            text = path.read_text(encoding="utf-8")
        except (OSError, UnicodeDecodeError):
            continue
        front = parse_front_matter(text)
        if front is None:
            continue
        raw_id = front.get("id")
        nodes.append(
            {
                "id": str(raw_id) if raw_id else None,
                "path": path.relative_to(root).as_posix(),
                "line_count": len(text.splitlines()),
                "front": front,
            }
        )
    return nodes
```

```python
GRAPH_HEADER = "# GENERATED by wiki_graph.py --build. Do not edit by hand.\n"
# 수동으로 쓰는 edge 와, 그 역으로 생성되는 edge 의 대응. 역 edge 를 손으로 쓰면 SSOT 가
# 둘이 되므로 검증이 block 한다 (Task 4).
DERIVED_EDGES = {"depends_on": "used_by", "affects": "defects"}
MANUAL_EDGES = ("depends_on", "related", "affects")
EDGE_KEYS = ("depends_on", "used_by", "affects", "defects", "related")
# 노드에 싣는 Front Matter 필드(스칼라·리스트). sources 는 map→리스트 변환이라 따로 다룬다.
_NODE_FIELDS = ("title", "tags", "aliases", "commit", "regression_test", "promoted_to_rule")


def _as_list(val) -> list[str]:
    """스칼라/리스트/None 을 문자열 리스트로 정규화한다."""
    if val is None:
        return []
    if isinstance(val, (list, tuple)):
        return [str(v) for v in val if v is not None]
    return [str(val)]


def build_graph(nodes: list[dict]) -> dict:
    """노드 목록에서 graph dict 를 만든다. 역 edge 는 여기서만 생성된다."""
    out_nodes: dict[str, dict] = {}
    edges: dict[str, dict[str, list[str]]] = {k: {} for k in EDGE_KEYS}
    for node in nodes:
        nid = node["id"]
        if not nid:
            continue
        front = node["front"]
        entry: dict = {"path": node["path"]}
        for field in _NODE_FIELDS:
            val = front.get(field)
            if isinstance(val, (list, tuple)):
                val = [str(v) for v in val if v is not None]
            if val:
                entry[field] = val
        sources = front.get("sources")
        if isinstance(sources, dict) and sources:
            entry["sources"] = sorted(str(k) for k in sources)
        elif sources:
            entry["sources"] = sorted(_as_list(sources))
        out_nodes[nid] = entry
        for kind in MANUAL_EDGES:
            targets = sorted(set(_as_list(front.get(kind))))
            if targets:
                edges[kind][nid] = targets
    for kind, derived in DERIVED_EDGES.items():
        for src, targets in edges[kind].items():
            for target in targets:
                edges[derived].setdefault(target, []).append(src)
    for derived in DERIVED_EDGES.values():
        edges[derived] = {k: sorted(set(v)) for k, v in edges[derived].items()}
    return {"version": 1, "nodes": out_nodes, "edges": edges}


def dump_graph(graph: dict) -> str:
    """결정적 YAML 직렬화. 키 정렬 고정이 drift 비교의 전제다."""
    import yaml

    body = yaml.safe_dump(
        graph, sort_keys=True, allow_unicode=True, default_flow_style=False, width=100
    )
    return GRAPH_HEADER + body
```

```python
import re

ID_RE = re.compile(r"^[a-z0-9-]+(\.[a-z0-9-]+)*$")


def _find_cycle(adjacency: dict[str, list[str]]) -> list[str] | None:
    """depends_on 그래프의 순환 하나를 경로로 반환한다. 없으면 None (반복 DFS — 재귀 깊이 무관)."""
    color: dict[str, int] = {}  # 0=진행중 1=완료
    for start in sorted(adjacency):
        if color.get(start) == 1:
            continue
        stack = [(start, iter(adjacency.get(start, ())))]
        path = [start]
        color[start] = 0
        while stack:
            node, it = stack[-1]
            nxt = next(it, None)
            if nxt is None:
                color[node] = 1
                stack.pop()
                path.pop()
                continue
            if color.get(nxt) == 0:
                return path[path.index(nxt) :] + [nxt]
            if color.get(nxt) != 1:
                color[nxt] = 0
                path.append(nxt)
                stack.append((nxt, iter(adjacency.get(nxt, ()))))
    return None


def validate_structure(root: Path, wiki: dict, nodes: list[dict], graph: dict) -> list[str]:
    """구조 위반(block 사유)을 모아 반환한다. 빈 목록이면 통과.

    여기서 잡는 것은 '정상 파싱된 wiki 안의 규칙 위반'뿐이다. 파싱 자체가 안 되는 것은
    collect_nodes 단계에서 이미 무시됐다 (Invariant #1).
    """
    problems: list[str] = []
    seen: dict[str, str] = {}
    for node in nodes:
        nid, path = node["id"], node["path"]
        front = node["front"]
        if not nid:
            problems.append(f"{path}: 필수 필드 id 가 없습니다")
            continue
        if not ID_RE.match(nid):
            problems.append(f"{path}: id '{nid}' 형식 위반 (허용: {ID_RE.pattern})")
        if nid in seen:
            problems.append(f"{path}: id '{nid}' 중복 — 이미 {seen[nid]} 가 사용 중")
        else:
            seen[nid] = path
        if not front.get("title"):
            problems.append(f"{path}: 필수 필드 title 이 없습니다")
        for derived in DERIVED_EDGES.values():
            if front.get(derived):
                problems.append(
                    f"{path}: '{derived}' 는 생성 필드입니다 — 손으로 쓰지 마세요 "
                    f"(역 edge 는 build 가 만듭니다)"
                )
        sources = front.get("sources")
        if isinstance(sources, dict):
            for src in sorted(sources):
                if not (root / src).exists():
                    problems.append(f"{path}: sources 경로 '{src}' 가 없습니다")
    known = set(graph["nodes"])
    for kind in MANUAL_EDGES:
        for src, targets in sorted(graph["edges"][kind].items()):
            for target in targets:
                if target not in known:
                    problems.append(f"{src}: {kind} 가 없는 id '{target}' 를 가리킵니다")
    cycle = _find_cycle(graph["edges"]["depends_on"])
    if cycle:
        problems.append("depends_on 순환: " + " → ".join(cycle))
    return problems
```

```python
def undirected_adjacency(graph: dict) -> dict[str, list[str]]:
    """모든 edge 를 방향 무시하고 합친 인접 리스트. orphan 판정과 --neighbors 가 공유한다."""
    adj: dict[str, set[str]] = {nid: set() for nid in graph["nodes"]}
    for kind in EDGE_KEYS:
        for src, targets in graph["edges"][kind].items():
            for target in targets:
                adj.setdefault(src, set()).add(target)
                adj.setdefault(target, set()).add(src)
    return {k: sorted(v) for k, v in adj.items()}


def _index_id(wiki: dict, graph: dict) -> str | None:
    """wiki.index 파일 경로에 해당하는 노드 id."""
    index_path = str(wiki.get("index") or "")
    for nid, entry in graph["nodes"].items():
        if entry["path"] == index_path:
            return nid
    return None


def collect_warnings(wiki: dict, nodes: list[dict], graph: dict) -> list[str]:
    """block 하지 않는 품질 경고를 모은다 (orphan · 파일 크기 · Rule 승격 신호)."""
    warns: list[str] = []
    start = _index_id(wiki, graph)
    if start:
        adj = undirected_adjacency(graph)
        seen = {start}
        queue = [start]
        while queue:
            cur = queue.pop()
            for nxt in adj.get(cur, ()):
                if nxt not in seen:
                    seen.add(nxt)
                    queue.append(nxt)
        for nid in sorted(set(graph["nodes"]) - seen):
            warns.append(f"orphan: '{nid}' 는 index 에서 도달할 수 없습니다 ({graph['nodes'][nid]['path']})")
    cap = int(wiki.get("max_lines") or 0)
    if cap > 0:
        for node in nodes:
            if node["line_count"] > cap:
                warns.append(
                    f"{node['path']}: {node['line_count']}줄 (> max_lines {cap}) — "
                    f"한 파일 한 개념으로 쪼개세요"
                )
    threshold = int(wiki.get("defect_rule_threshold") or 0)
    if threshold > 0:
        by_tag: dict[str, list[str]] = {}
        promoted: set[str] = set()
        for node in nodes:
            nid = node["id"]
            if not nid or not nid.startswith(DEFECT_PREFIX):
                continue
            for tag in _as_list(node["front"].get("tags")):
                by_tag.setdefault(tag, []).append(nid)
                if node["front"].get("promoted_to_rule"):
                    promoted.add(tag)
        for tag in sorted(by_tag):
            if len(by_tag[tag]) >= threshold and tag not in promoted:
                warns.append(
                    f"Rule 승격 검토: tag '{tag}' 로 defect 가 {len(by_tag[tag])}건인데 "
                    f"promoted_to_rule 이 없습니다"
                )
    return warns
```

```python
def _last_commit(root: Path, rel: str) -> str:
    """해당 파일의 마지막 커밋 한 줄 요약. 조회 실패면 빈 문자열.

    drift 를 만든 사람과 막히는 사람이 다를 수 있으므로(설계 4절 실패 모드),
    실패 메시지가 원인 커밋을 지목해 버그로 오해되지 않게 한다.
    """
    try:
        out = subprocess.run(
            ["git", "log", "-1", "--format=%h %an %s", "--", rel],
            cwd=str(root), capture_output=True, text=True, encoding="utf-8", timeout=5,
        )
    except Exception:
        return ""
    return out.stdout.strip() if out.returncode == 0 else ""


def _drifted_paths(graph: dict, actual_text: str | None) -> list[str]:
    """디스크 graph 와 재빌드 결과가 어긋난 노드의 파일 경로 (정렬).

    drift 를 만든 사람과 막히는 사람이 다를 수 있으므로, 실패 메시지는 '어긋났다'가 아니라
    '어느 문서가 어긋났다'를 말해야 한다. 판별 불가(파일 없음·파싱 실패)면 빈 목록이다.
    """
    if actual_text is None:
        return []
    try:
        import yaml

        disk = yaml.safe_load(actual_text) or {}
    except Exception:
        return []
    disk_nodes = disk.get("nodes") or {}
    live_nodes = graph.get("nodes") or {}
    changed = {
        nid
        for nid in set(disk_nodes) | set(live_nodes)
        if disk_nodes.get(nid) != live_nodes.get(nid)
    }
    disk_edges = disk.get("edges") or {}
    for kind in EDGE_KEYS:
        on_disk = disk_edges.get(kind) or {}
        live = graph["edges"][kind]
        for nid in set(on_disk) | set(live):
            if on_disk.get(nid) != live.get(nid):
                changed.add(nid)
    paths = []
    for nid in sorted(changed):
        entry = live_nodes.get(nid) or disk_nodes.get(nid) or {}
        if entry.get("path"):
            paths.append(entry["path"])
    return paths
```

```python
def cmd_stale(root: Path) -> int:
    """sources 의 기록 sha 와 실제 마지막 커밋을 비교해 JSON 배열로 낸다. 항상 0.

        if not isinstance(sources, dict):

        for src in sorted(sources):
            recorded = sources[src]
            recorded = str(recorded) if recorded else None

            try:
                res = subprocess.run(
                    ["git", "log", "-1", "--format=%H", "--", src],

            if recorded and current.startswith(recorded):
                continue
            out.append(
                {
                    "id": node["id"],
                    "path": node["path"],
                    "source": src,
                    "recorded": recorded,
                    "current": current,
                }
            )
    print(json.dumps(out, ensure_ascii=False, indent=2))
    return 0
```

```python
def _prioritized_adjacency(graph: dict) -> dict[str, list[str]]:
    """EDGE_KEYS 순서(depends_on → used_by → affects → defects → related)로 이웃을 늘어놓는다.

    같은 hop 안에서 구조적 의존이 느슨한 연관보다 먼저 예산을 차지하게 하는 장치다.
    방향은 무시한다 (설계 3절 도달 판정과 같은 규칙).
    """
    adj: dict[str, list[str]] = {nid: [] for nid in graph["nodes"]}
    for kind in EDGE_KEYS:
        for src, targets in graph["edges"][kind].items():
            for target in targets:
                adj.setdefault(src, []).append(target)
                adj.setdefault(target, []).append(src)
    out: dict[str, list[str]] = {}
    for nid, targets in adj.items():
        seen: set[str] = set()
        out[nid] = [t for t in targets if not (t in seen or seen.add(t))]
    return out


def neighbors(
    graph: dict, nodes: list[dict], start: str, budget: int
) -> tuple[list[str], int, int]:
    """진입점에서 BFS 로 넓히며 예산(줄 수) 안의 파일 경로를 모은다.

    깊이 제한은 없다 — 예산이 유일한 제동이고, 순환은 visited 집합이 처리한다.
    진입점 자신은 예산을 넘겨도 항상 포함한다 (빈 결과 방지).
    """
    if start not in graph["nodes"]:
        return [], 0, 0
    lines = {n["id"]: n["line_count"] for n in nodes if n["id"]}
    adj = _prioritized_adjacency(graph)
    paths = [graph["nodes"][start]["path"]]
    total = lines.get(start, 0)
    seen = {start}
    queue = [start]
    cut = 0
    while queue:
        cur = queue.pop(0)
        for nxt in adj.get(cur, ()):
            if nxt in seen:
                continue
            seen.add(nxt)
            cost = lines.get(nxt, 0)
            if total + cost > budget:
                cut += 1
                continue
            total += cost
            paths.append(graph["nodes"][nxt]["path"])
            queue.append(nxt)
    return paths, total, cut


def cmd_neighbors(root: Path, start: str, budget: int | None) -> int:
    """이웃 문서 경로를 stdout 으로. 조회용이므로 언제나 0 이다."""
    wiki, nodes, graph = _load(root)
    if wiki is None:
        return 0
    limit = budget if budget is not None else int(wiki["context_lines"])
    paths, total, cut = neighbors(graph, nodes, start, limit)
    if not paths:
        print(f"알 수 없는 id: '{start}'", file=sys.stderr)
        return 0
    for path in paths:
        print(path)
    print(f"# {len(paths)}개 문서 {total}줄 / 예산 {limit}줄, 잘림 {cut}개", file=sys.stderr)
    return 0
```

```python
def _wiki_verify_command(root: Path) -> str | None:
    """flow-config.wiki 가 살아 있으면 wiki 검증 명령, 아니면 None.

    경로를 __file__ sibling 으로 잡는다: 이 스크립트는 플러그인 캐시와 호스트 복사본
    양쪽에서 실행되며 sibling 참조만이 두 모드 모두에서 성립한다.
    """
    script = Path(__file__).resolve().parent / "wiki_graph.py"
    if not script.is_file():
        return None
    try:
        try:
            from wiki_graph import load_wiki_config  # 직접 실행 (sibling)
        except ImportError:
            from scripts.wiki_graph import load_wiki_config  # 패키지 (test/dev)
        if load_wiki_config(root) is None:
            return None
    except Exception:
        return None  # Invariant #1 — wiki 판정 실패는 통과
    return f'{sys.executable} "{script}" --verify'
```

````markdown
# Wiki-Init — LLM Wiki Setup Wizard

기존 문서를 wiki 노드로 이관하고 `graph.yaml` 을 세운다. 임베딩을 쓰지 않는다 —
관계는 Front Matter 에 사람이 적고, graph 는 그것을 기계적으로 읽는다.

**전제**: `.claude/harness-tier/config/flow-config.yaml` 이 있어야 한다. 없으면
[`/flow-init`](../flow-init/SKILL.md) 을 먼저 실행하라고 안내하고 **중단**한다.

재실행은 증분이다. 이미 Front Matter 가 있는 문서는 건드리지 않는다.

## 1. wiki root 확인

`AskUserQuestion` 으로 확정한다. 기본값은 `docs/` — `/harness-init` 산출물과 같은 트리에
두어 문서 집합이 하나로 유지된다.

## 2. 스캔

root 아래 `.md` 를 훑어 이관 후보 표를 만든다. 각 행은 파일 경로 · 줄 수 · H2 개수 ·
Front Matter 유무다. **줄 수가 크고 H2 가 여럿인 파일이 곧 여러 개념이 든 파일**이다.

## 3. 선별

사용자가 이관할 문서를 고른다. 후보가 많으면 배치로 나눠 묻는다. 고르지 않은 문서는
그대로 둔다 — Front Matter 가 없으면 wiki 밖이라 검증 대상이 아니다.

## 4. 분리

선택된 문서를 H2 단위로 쪼개 새 파일로 만든다. **원본은 지우지 않는다** — 해당 절 자리에
새 문서 링크를 남긴다. 되돌리기 쉬운 상태를 유지하는 것이 목적이다.

## 5. Front Matter 부여

`id` 는 경로에서 기계적으로 만든다: `docs/code-style/python.md` → `code-style.python`
(디렉터리 구분자를 `.` 로, 확장자 제거, 소문자화). 사람이 짓지 않으므로 충돌하지 않는다.

`related` · `depends_on` 은 기존 문서를 읽고 **추천**한 뒤 사용자 확인을 받아 확정한다.
`used_by` · `defects` 는 **절대 쓰지 않는다** — 생성 필드이고, 손으로 쓰면 검증이 막는다.

`sources` 는 그 문서가 설명하는 코드 경로를 map 으로 적는다. sha 는 `null` 로 두면
[`doc-sync`](../doc-sync/SKILL.md) 가 채운다.

장애 문서를 만들 때는
[`defect-template.md`](references/defect-template.md) 의 5단 본문 구조를 따른다.

## 6. index 생성

`<root>/index.md` 를 만들거나 갱신해 **모든 노드를 링크**한다. 여기서 도달할 수 없는
노드는 orphan 경고가 된다.

## 7. flow-config 갱신

`wiki` 블록을 upsert 한다. 블록만 교체하고 나머지 설정은 보존한다.

  defect_rule_threshold: 3
````

```markdown
  **Timing is bound to that bucket's gate existing in the tier**: the `docs` tier has
  neither *bucket* gate, so host custom checks never run on a docs commit. It is no longer
  short-circuited outright, though — `wiki` runs before that return (see below).
```

**(b) 같은 절의 Runtime gates 목록**, `security-scan` 항목 뒤에 세 번째 runtime gate 를 넣는다:

```markdown
  - **`wiki`** — not a timing bucket. When `flow-config.wiki` is enabled it runs
    `wiki_graph.py --verify`, a read-only check that the committed `graph.yaml` still
    matches the docs' front matter and that no structural rule is broken. It runs on
    **every tier including `docs`** — a docs commit is exactly when the graph drifts.
    No wiki configured (absent · `enable: false` · missing root) → no command at all,
    so a repo without a wiki never notices this gate. The graph is **built** by
    `/doc-sync`, never by the hook and never by CI.
```

**(c) `rules/risk-tiers.md:166`** 의 표 행에서 gates 열을 갱신한다:

```markdown
| Work on `feature/*` / `fix/*` → integration branch | **Docs** (no code) / **Dev** (any code) | Docs: doc-sync, wiki · Dev: precommit, review, doc-sync, wiki |
```

```markdown
    Where the project has an LLM Wiki, it also refreshes each node's front matter
    `sources` sha and rebuilds `graph.yaml` (Mode W) — the `wiki` runtime gate then
    verifies that rebuild.
```
